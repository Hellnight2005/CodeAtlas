🚀 Local-First Graph-Native Code Intelligence

Stop making AI read raw files.
Let the graph guide the AI.

CodeAtlas indexes your codebase into a high-performance Neo4j knowledge graph, connecting to AI Agents (Cursor, Antigravity, Claude) over MCP with zero cloud dependency.

$ codeatlas start
⚡

Graph-RAG Retrieval

Combines concept normalization, lexical search, and 6-factor Neo4j graph reranking to deliver exact file and line ranges without token bloat.

🔒

100% Local Privacy

Zero source code or metadata leaves your machine. Operates completely offline with SQLite and local Neo4j persistent storage.

🤖

8 Progressive MCP Tools

Equips AI agents with search, symbol lookup, caller/callee traversal, dependency inspection, impact analysis, and route execution tracing.

🚀

Bounded Concurrency Indexer

Multi-core CPU parallel AST parser pool featuring SHA-256 content hash skipping for sub-second incremental re-indexing.

🎯

Architectural Flow Derivation

Automatically derives layered execution paths from HTTP entry points (POST /upload) down to database operations.

📊

Full-Screen Dashboard

Next.js 16 interactive graph workspace with tabbed node inspector, search filters, and keyboard navigation shortcuts.

bash — CodeAtlas CLI

# 1. Install & Link CodeAtlas globally

$ git clone https://github.com/Hellnight2005/CodeAtlas-.git

$ cd CodeAtlas- && npm install && npm link


# 2. Run in any project directory

$ cd /path/to/your/project

$ codeatlas start


✔ CodeAtlas Core Infrastructure Ready

- REST API Engine: http://localhost:5001

- Dashboard UI: http://localhost:3001

- MCP Server: stdio ready
