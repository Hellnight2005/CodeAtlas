# Installation Guide

CodeAtlas is local-first software built on the Node.js runtime.

## Prerequisites

- **Node.js**: Version 18.0.0 or higher (v20+ recommended).
- **npm**: Version 9.0.0 or higher.

## Global Installation

Install CodeAtlas globally via npm:

```bash
npm install -g codeatlas
```

Alternatively, link the repository locally:

```bash
git clone https://github.com/Hellnight2005/CodeAtlas-.git
cd CodeAtlas-
npm install
npm link
```

## Verifying Installation

Check that CodeAtlas is installed correctly:

```bash
codeatlas doctor
```
